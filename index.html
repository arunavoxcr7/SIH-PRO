How It Works — Simple 6-Step Workflow

Engineered for Oil & Gas Enterprise Project Control Teams
1

1. PLAN

Planner creates L4 Activities (e.g. WP03-CIV-0100) and establishes the initial baseline project schedule.

2

2. CAPTURE

Site team records actual on-ground execution L5/L6 Events (e.g. eve_000001) from field progress reports.

3

3. LINK

Execution Events are associated with the correct planned L4 Activity code based on location, area, and discipline.

4

4. UPDATE

Activity progress percentage is automatically updated based on completed on-ground Events.

5

5. REVIEW

Planner verifies uncertain, conflicting, or unmatched site updates in the Review Centre.

6

6. ANALYZE

Project progress, area completion, and historical memory become available for executive decision-making.
